Database: Transcriptome of Irritable Bowel Syndrome (TIBS)


Please input official gene symbols (For example DUOX2, or PPARG).

 

 

Transcriptome of Irritable Bowel Syndrome

 

 

All genes included in the TIBS database could be found here.

If you still cannot find the genes you are interested in, please check their official gene symbols at www.genecards.org.

Batch search

You may enter multiple offical gene symbols separated by spaces for the batch searching of the TIBS database (for example "DUOX2 PPARG HSPA6").

Fuzzy search

You may enter a SINGLE query string for the fuzzy searching of the TIBS database (For example, "DUOX" or "PAR").
